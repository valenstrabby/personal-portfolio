# Project Scope Statement

## Project Title

My Personal Website Final Project

## Project purpose

The main purpose of this project is to create a complete website that presents information aboutmyself, including my interests and background. It will be easy to navigate, visually organized, and published online using GitHub Pages.

## Project description

For my final project, I will build a multi-section website using HTML,and CSS. Thw website will include a homepage, information about my interests, a section of my hometown, and a closing section. The site will use clear headings, readable text, colors, spacing, and images or embedded content when it's appropiate.

## Project objectives

- Create a finished website using HTML, and CSS.

- Have the website organized and easy to read.

- Include styling that improves the appearance.

- Publish the website online using GitHub Pages.

- Make sure all the required files are included and correctly linked.

## Deliverables

The final project will include:

- 'index.html'

- 'style.css'

- 'README.md'

- Required images or extra files.

- A live GitHub Pages website.

- A GitHub repository containing the projects files.

## In Scope

This project will include:

- A homepage with a title and introduction.

- Styled headings and paragraphs.

- A section about my interests and hobbies.

- A section about my background.

- Basic navigation or organized page sections.

- CSS stylingfor colors, fonts, spacing, and layout.

- A published version of the website on GitHubPages.

## Out of Scope

This project will not include:

- A login system

- A shopping cart

- A database

- Advance JavaScript features

- Private personal information

## Projects Requirements

The website must:

- Use valid HTML structure

- Use an external CSS file

- Be organized and readable

- Include content related to the chosen topic

- Be uploaded to GitHub

- Be published through GitHub Pages

- Include a README file explaining the project

## Stakeholders

The main stakeholder for this project is my professor. I am also a stakeholder because I am responsible for designing, building, testing, and submitting the final website.

## Assumptions

I assume that I will have access to my computer, my code editor, GitHub, Canvas, and the internet while working on this project. I also assume that GitHub Pages will be available for publishing the website.

## Constraints

### Time


The project must be completed before the final project deadline. I will need to manage my time so I can plan, build, test, and submit the website on time.

### Quality

The website needs to be clear, organized, and functional. The HTML and CSS should work correctly, and the design should be easy for visitors to understand.

### Budget

There is no money budget for this project. The main cost is the time needed to complete the website.

## Acceptance Criteria

The project will be considered complete when:

- The website has working HTML and CSS files.

- The design is styled and readable.

- The required content is included.

- The project files are uploaded to GitHub.

- The website is live on GitHub Pages.

- The final Markdown scope file is submitted in Canvas.

## Project Milestones

1. Choose the final project topic.

2. Create the project scope statement.

3. Build the HTML structure.

4. Add CSS styling.

5. Test the website in a browser.

6. Upload the project to GitHub.

7. Publish the website using GitHub Pages.

8. Submit the final project.
