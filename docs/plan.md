# Project Plan

## Project Goal

The goal of this project is to create a complete website that includes a homepage, an about page, consistent styling, and project documentation. The website will be published using GitHub Pages.

## Work Breakdown Structure

1. Planning
- Choose the website topic
- Write the project scope statement
- Identify required pages and files

2. Website Development
- Create `index.html`
- Create `about.html`
- Create `style.css`
- Link both HTML pages to the CSS file

3. Documentation
- Create `README.md`
- Create `docs/scope.md`
- Create `docs/plan.md`
- Create `docs/retrospective.md`

4. Testing
- Test links between pages
- Check that CSS works on both pages
- Make sure the live GitHub Pages website loads correctly

5. Submission
- Push all files to GitHub
- Check repository organization
- Submit the GitHub repository link in Canvas

## Schedule

| Task | Estimated Time |
|---|---:|
| Plan project topic and scope | 1 hour |
| Build homepage | 1 hour |
| Build about page | 1 hour |
| Add CSS styling | 1 hour |
| Create documentation files | 1 hour |
| Test and publish website | 30 minutes |

## Risk Analysis

| Risk | Impact | Response |
|---|---|---|
| GitHub Pages does not update right away | Medium | Wait a few minutes and check settings |
| CSS file does not connect correctly | High | Check that the link tag uses `href="style.css"` |
| Missing required files | High | Compare the repository to the assignment checklist |
| Links between pages do not work | Medium | Test every link in the browser before submitting |
