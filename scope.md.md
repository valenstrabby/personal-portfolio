# Project Scope

## Project Purpose
The purpose of this project is to create a personal introduction webpage that presents information about myself, my academic interests, career goals, hobbies, and GitHub profile. This project demonstrates my understanding of basic HTML structure and web development concepts.

## Description
The webpage will include my name, major, professional interests, career goals, personal hobbies, and a link to my GitHub profile. The page will be built using standard HTML elements and organized in a clear and readable format.

## Desired Results
- Create a valid HTML document.
- Display my personal information professionally.
- Demonstrate proper use of HTML headings, paragraphs, lists, and hyperlinks.
- Successfully host and manage the project using GitHub.

## Exclusions
- Advanced CSS styling.
- JavaScript functionality.
- Database integration.
- User authentication or login systems.
